# Обработка изображений

11 работ на Python и NumPy. Для каждой работы есть отдельная папка с `work.ipynb`.
Все библиотеки установлены в общем окружении `.img_proc_env`.

## Запуск

В терминале из этой папки:

```sh
source .img_proc_env/bin/activate
python -m notebook
```

В VS Code открыть работу, выбрать **Select Kernel → Existing Jupyter Server**,
вставить адрес сервера из терминала вместе с `?token=…` и выбрать
**Python (.img_proc_env)**. 

Ячейки запускать сверху вниз. Пути `data/scene.jpg`, `data/building.jpg`
рассчитаны на рабочую папку ядра `обработка изображений`, содержащую
`data/` и `.img_proc_env/`. В VS Code открыть эту общую папку как рабочую область.
Рабочую папку текущего ядра показывает команда `%pwd`.
При запуске через браузер Jupyter ядро обычно начинает работу из подпапки задания;
команда `%cd ..` переводит его в общую папку проекта.

`start.command` также запускает сервер в общем окружении.

## Работы

| № | Ноутбук | Тема |
|---|---|---|
| 1 | [Цвет и яркость](01_grayscale/work.ipynb) | Чтение JPEG/GIF, среднее RGB, BT.601/709, палитры |
| 2 | [Гистограммы](02_histograms/work.ipynb) | Яркость, контраст, гамма, автоконтраст |
| 3 | [Автоконтраст](03_autocontrast/work.ipynb) | Отсечение выбросов, процентили, среднее 128 |
| 4 | [Сдвиг и поворот](04_shift_rotate/work.ipynb) | Целый и дробный сдвиг, два способа интерполяции |
| 5 | [Масштаб и проекция](05_scale_projective/work.ipynb) | Увеличение, уменьшение, проективная матрица |
| 6 | [Свёртка](06_convolution/work.ipynb) | Постоянные и гауссовы ядра |
| 7 | [Сохранение границ](07_edge_filters/work.ipynb) | Медианный и билатеральный фильтры |
| 8 | [Глобальная бинаризация](08_thresholding/work.ipynb) | Ручной порог, Оцу, гамма |
| 9 | [Ниблэк](09_niblack/work.ipynb) | Локальный порог и подбор параметров |
| 10 | [Морфология](10_morphology/work.ipynb) | VH–GW, эрозия, дилатация, открытие и закрытие |
| 11 | [Кэнни](11_canny/work.ipynb) | Градиенты, направления, утончение и пороги |

Импорты собраны в первой кодовой ячейке. Функции каждой работы находятся
в её ноутбуке. `%matplotlib inline` выводит рисунки прямо в ячейках.
Pillow читает файлы, NumPy выполняет вычисления, Matplotlib строит графики.

Изображения лежат в `data/`, исходники — в `data/originals/`.
[Источники изображений](data/SOURCES.md).

## Создание окружения на другом компьютере

```sh
python3.13 -m venv .img_proc_env
.img_proc_env/bin/python -m pip install -r requirements.txt
.img_proc_env/bin/python -m ipykernel install --prefix "$PWD/.img_proc_env" --name img-proc --display-name 'Python (.img_proc_env)'
```
